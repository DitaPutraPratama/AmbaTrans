# Keamanan

## Versi yang didukung
Perbaikan keamanan hanya dibuat untuk [rilis terbaru](https://github.com/DitaPutraPratama/AmbaTrans/releases/latest).

## Melaporkan celah keamanan
Jangan laporkan celah keamanan lewat issue publik.

Laporkan secara privat lewat tab **Security** → **Report a vulnerability** di repo ini ([tautan langsung](https://github.com/DitaPutraPratama/AmbaTrans/security/advisories/new)). Sertakan:
- versi AmbaTrans, versi Android, dan model HP;
- langkah untuk memunculkan masalahnya;
- dampaknya, misalnya API key bocor, screenshot tersimpan, atau data terkirim ke luar perangkat.

Ini proyek sukarela yang dikelola satu orang. Laporan akan dibalas secepat mungkin, tetapi tidak ada jaminan waktu.
